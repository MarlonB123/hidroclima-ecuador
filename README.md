# HidroClima Ecuador

**Pipeline de Datos para la Predicción de Lluvias en Zonas de Interés Hidroeléctrico**

Proyecto Integrador, Sexto Semestre  
Ingeniería en Sistemas de la Información, Universidad Internacional del Ecuador (UIDE)

## Descripción

HidroClima Ecuador es un prototipo académico que obtiene datos meteorológicos históricos desde la API de Open-Meteo para dos zonas de interés hidroeléctrico de la vertiente amazónica del Ecuador: la captación de Coca Codo Sinclair y el embalse Mazar. Los datos se limpian, transforman y almacenan mediante un pipeline ETL en Google Colab, y se utilizan para entrenar y comparar modelos de Machine Learning que predicen la ocurrencia de lluvia al día siguiente. Los resultados se presentan en un dashboard.

El proyecto integra las asignaturas de Desarrollo de Proyectos de Sistemas de Información, Tendencias en Tecnologías Emergentes y Modelos de Negocios Digitales, Prácticas y Herramientas de Big Data, Machine Learning y Ciberseguridad.
